# 🔵 TypeScript Learning & Ecosystem

A personal knowledge base and sandbox dedicated to learning TypeScript and exploring its ecosystem.

## What's Inside

- **Notes & Fundamentals:** Core type system concepts, compiler behavior, and configuration (`tsconfig`).
- **Advanced Typing:** Generics, utility types, type guards, and complex type patterns.
- **Dev Tools & Ecosystem:** Overviews, setups, and experiments with type-checkers, bundlers, runtimes, and TS-first libraries.
- **Practice:** Type challenges, code snippets, and mini-experiments.
